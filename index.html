Getting started

Install a skill

Each skill is a small .zip — a Markdown instruction file plus references. You never open it: download once, upload to ChatGPT or Claude, then work in plain English. You only add the ZIP once; after that the skill is available across chats.

For ChatGPT

Install in ChatGPT

  1. Download the skill ZIP. Keep it zipped.
  2. Upload once where you manage Skills or custom GPT knowledge, and wait for the upload to finish.
  3. Start with your goal in plain language, e.g. “Help me brief this case.”

For Claude

Install in Claude

  1. Download the skill ZIP. Do not unzip it.
  2. Add it to Claude in the project or Skill area, then confirm the skill appears as available.
  3. Use natural language — start with your goal and ask Claude to use the skill.

Access to RCLL-provided tools is limited to current SLS community members and uses Stanford SSO. Confirm your course’s AI policy with the instructor. For access, tools, or research help, contact library@law.stanford.edu.
